# Hyun Eunbin Portfolio

현은빈의 Robotics · Physical AI 포트폴리오 웹사이트입니다.

## 주요 내용

- Computer Vision, Edge AI, ROS 2 기반 프로젝트
- Robotics · Embedded / AI · Computer Vision / Simulation · 3D 기술 스택
- 교육 배경과 논문·특허·수상 성과

## 로컬 실행

```bash
pnpm install
pnpm dev
```

## 수정 및 배포

`main` 브랜치에 변경사항을 푸시하면 GitHub Actions가 사이트를 빌드해 [eunbin-hyun.github.io](https://eunbin-hyun.github.io/)에 자동 배포합니다.
